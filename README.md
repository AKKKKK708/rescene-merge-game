# 合成大 RESCENE

一款可直接在手机或电脑浏览器中运行的像素风落物合成小游戏。

## 在线游玩

[点击这里直接在线游玩](https://akkkkk708.github.io/rescene-merge-game/)，无需登录。

## 玩法介绍

移动鼠标或在手机上拖动来调整掉落位置，点击或松手投放图片。两个相同等级的图片接触后会合成为下一级，目标是在有限空间内持续合成并获得更高分数。

### 得分机制

普通合成按照合成后的图片等级计分：第 `N` 级图片得分为 `N × (N - 1) ÷ 2`。两个第 11 级图片完成最终合成时获得 500 分。

| 合成结果 | 本次得分 |
| --- | ---: |
| 第 2–5 级 | 1、3、6、10 分 |
| 第 6–8 级 | 15、21、28 分 |
| 第 9–11 级 | 36、45、55 分 |
| 两个第 11 级完成最终合成 | 500 分 |

个人最高分和最近 10 局成绩保存在当前设备的浏览器中，不会跨设备同步。

### 失败机制

图片进入场地至少 0.8 秒后，如果顶部持续越过警戒线并且运动速度已经较低，就会开始积累警告。警告持续约 1.6 秒后，本局进入结束判定；图片离开警戒区域或重新发生明显运动时，警告会逐渐消退。

没有复活币时游戏直接结束；持有复活币时可以选择复活，或结束本局并记录成绩。

### 复活币获得与使用

- 两个第 11 级图片完成最终合成时，获得 1 枚复活币。
- 当前一局的累计分数每达到 2000 分的整数倍，额外获得 1 枚复活币，例如 2000、4000、6000 分。
- 复活会消耗 1 枚复活币，清理警戒区域中的顶部堆积图片，并从当前分数继续游戏。
- 复活币只在当前一局中使用，重新开始后会归零。
